# ASCII Toool

A powerful and elegant tool to transform your images and videos into stunning ASCII art, halftone patterns, and more—all in your browser.

## Features

- **Real-time Processing:** Upload any image or video and watch it transform instantly.
- **Multiple Rendering Modes:** ASCII, Halftone, Bitmap, Posterize, and Tiles.
- **Full Customization:** Control character sets, typography, colors, and image adjustments.
- **Export Options:** Download your creations as high-quality images or videos.
- **Privacy First:** All processing happens locally in your browser. No files are uploaded to any server.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/igormzs/ascii-art-tool.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Tech Stack

- **Core:** TypeScript, HTML5 Canvas
- **Build Tool:** Vite
- **Styling:** Vanilla CSS (Glassmorphism design)
- **Deployment:** Vercel
